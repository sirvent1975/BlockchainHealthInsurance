# Blockchain-Based Health Insurance Fraud Detection

This repository accompanies the research paper _"A Blockchain-Based Model for Fraud Detection in Health Insurance"_, proposing a multi-layered architecture to detect and prevent fraudulent behavior in healthcare claims using smart contracts.

## 🔍 Purpose

To provide a conceptual and technical foundation for the development of blockchain-based fraud detection systems in the health insurance domain. The repository includes:

- A prototype smart contract (`Solidity`)
- Architectural overview and explanation
- Sample data inputs for simulation
- Documentation and figures

## 🧱 Smart Contract

The `contracts/HealthInsuranceFraudDetection.sol` file defines a Solidity smart contract to simulate:

- Policy registration
- Claim submission
- Detection of duplicate service claims
- Basic fraud alert mechanism

## 🖼 Architecture

The `diagrams/` folder contains the system's conceptual architecture (as shown in the paper), including the four-layer model and stakeholder interaction.

## 📄 Documentation

A description of the full model and interactions is available in the `docs/` folder.
